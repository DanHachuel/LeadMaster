⚡ Automação de Prospecção e Conteúdo

LeadMaster

Ferramenta local de automação para prospecção de leads e publicação de conteúdo em redes sociais (YouTube, TikTok, Instagram, Pinterest e Meta), utilizando exclusivamente APIs oficiais.

O LeadMaster é um SaaS local (instalável via npx) que unifica CRM, extratores de leads, agentes de IA e um pipeline de produção de conteúdo — com todos os dados armazenados 100% na máquina do usuário, sem nuvem.

🗂️ CRM com Kanban

Gestão completa de leads com funil arrastável (Leads → Em contato → Proposta → Fechado), importação em massa e agente de IA que sugere movimentações e enriquece cadastros.

🕸️ Extratores de Leads

Extração de contatos comerciais públicos do Google Maps, Instagram e CNPJ (BrasilAPI e provedores públicos), com pré-visualização antes da importação.

🤖 Agentes de IA

Agente de disparo com templates personalizáveis (texto e áudio) e agente de atendimento por texto ou voz — conectados a LLMs (APIs OpenAI-compatíveis) e ao OpenOutreach.

🎬 Pipeline de Vídeos Faceless

Geração de roteiros com IA, produção de vídeos no formato wide 16:9 e shorts 9:16 e upload automático para o YouTube (não listado → público), respeitando os limites das APIs oficiais.

🔧 Como funciona

O LeadMaster roda localmente no computador do usuário e orquestra todo o fluxo: captação de leads → gestão no CRM → contato via agentes de IA → produção de conteúdo → publicação nas redes sociais.

Fluxo completo: extração/importação de leads → CRM Kanban → disparo de mensagens → geração de roteiro com IA → produção do vídeo → upload via API oficial da plataforma (com as configurações de privacidade definidas pelo usuário).

📡 Integrações via APIs oficiais

O LeadMaster utiliza apenas APIs oficiais das plataformas, com autenticação OAuth e tokens fornecidos pelo próprio usuário:

▶️ YouTube

API: YouTube Data API v3

Escopos: youtube.upload

Upload automático de vídeos (wide e shorts) com título, descrição e controle de privacidade (público / não listado / privado).

📱 TikTok

API: Content Posting API

Escopos: user.info.basic, video.upload, video.publish

Publicação de vídeos com revisão antes do envio, respeitando os limites e políticas da plataforma.

📸 Instagram

API: Instagram Graph API

Escopos: instagram_basic, instagram_content_publish, pages_show_list

Publicação de conteúdo (imagens, Reels e vídeos) em contas comerciais próprias do usuário.

📌 Pinterest

API: Pinterest API v5

Escopos: boards:read, boards:write, pins:read, pins:write

Criação automatizada de Pins com imagens ou vídeos, incluindo link e descrição personalizados.

👥 Meta (Facebook)

API: Meta Graph API

Escopos: pages_manage_posts, pages_read_engagement, publish_video

Publicação de conteúdo em Páginas do Facebook gerenciadas pelo próprio usuário.

Publicações são feitas somente nas contas do próprio usuário, mediante autenticação explícita, e o conteúdo é sempre revisável antes de ser enviado.
